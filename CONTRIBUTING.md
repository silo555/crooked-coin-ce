# Contributing

Run the host tests and native transfer validator described in [BUILDING.md](docs/BUILDING.md). A gameplay change should have a reproducible test and explain whether it changes verified PC behavior or an intentional CE adaptation.

Keep the original art, branding and writing independent. Do not submit commercial executables, extracted source/assets, personal saves, ROMs, account data, or credentials. Numerical observations with build identifiers, source hashes and a clear method are useful.

For device reports, include calculator model, OS, launcher, CE library version, exact keys/actions, expected behavior and whether progress was recovered. Back up saves before trying experimental builds. Use a minimal disposable reproduction instead of uploading personal saves.
